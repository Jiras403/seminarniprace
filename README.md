Webová stránka zaměřená na shromažďování a archivaci rychlodabingů. Obsahovat bude databázi filmů, u kterých byl nalezen rychlodabing, dobové skeny videokazet, ukázky dabingů a případně také kontakty na sběratele, kteří daný dabing vlastní.

Vizuální styl webu bude inspirován internetovými stránkami z 90. let a začátku 21. století. Cílem je zachovat dobovou atmosféru, jednoduchý vzhled a nostalgickou podobu tehdejšího webu.
